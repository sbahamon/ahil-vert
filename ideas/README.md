# Video Ideas Backlog

This folder contains video ideas waiting to be developed.

## How to Add Ideas

Create a new markdown file with the idea name, e.g., `parking-reform-myth.md`:

```markdown
# Video Idea: [Title]

## Type
Data Drop / Myth Buster / Explainer / Call to Action

## Summary
One-sentence description of the video concept.

## Hook
What's the attention-grabbing opening?

## Key Points
- Point 1
- Point 2
- Point 3

## Data Sources
- Source 1
- Source 2

## Campaign Connection
Which AHIL campaign does this support?

## Priority
High / Medium / Low

## Notes
Any additional context or considerations.
```

## Idea Sources

Ideas can come from:

1. **AHIL campaigns** - 4-flats by right, parking reform, Illinois Housing Opportunity Act
2. **Housing policy news** - New legislation, city council votes, studies
3. **Content calendar** - Upcoming events, votes, deadlines
4. **User feedback** - What questions do people ask? What myths persist?
5. **Performance data** - What topics get engagement?

## Weekly Batch Process

Each week, Claude will suggest 3-5 new video ideas based on:

- Current AHIL priorities
- Recent news
- Content gaps
